ไฟล์:
index.html     ลูกค้าสแกน QR ประจำโต๊ะ -> เมนูอาหาร
owner.html     เจ้าของร้าน: ภาพรวม / ครัว / เคาน์เตอร์ / จัดการออเดอร์ / เมนู / QR
customer.js / owner.js / shared.js / style.css / config.js
setup.sql      สร้างฐานข้อมูลและ RLS ใน Supabase

ทดลองก่อน (ไม่มี Supabase):
1. แตก ZIP แล้วเปิด index.html?table=A-01 ในเบราว์เซอร์
2. เปิด owner.html อีกแท็บ กด เข้าสู่ระบบ
3. เพิ่มอาหารจากฝั่งลูกค้า แล้วดูครัวในแท็บเจ้าของร้าน
4. เพิ่ม/ลบเมนู ปรับสถานะอาหาร แก้ไขและยกเลิกบิล ลองพิมพ์ QR ประจำโต๊ะ
5. DEMO ใช้ localStorage + BroadcastChannel จึงซิงก์เฉพาะเบราว์เซอร์เดียวกัน
   ไม่ใช่ระบบล็อกอินจริง ไม่ควรอัปโหลด DEMO ขึ้นเว็บสาธารณะ!

ใช้งานจริงหลายอุปกรณ์ผ่าน GitHub Pages + Supabase:
1. สร้างโปรเจกต์ Supabase ของร้าน
2. เปิด SQL Editor แล้ว RUN setup.sql เพียงครั้งเดียวในโปรเจกต์ใหม่
3. Authentication > Users > Add user: สร้างบัญชีเจ้าของร้าน (อีเมล+รหัสผ่าน)
4. SQL Editor: รันคำสั่ง insert into public.staff_roles(...) ตามคอมเมนต์ท้าย setup.sql
5. Project Settings > API: นำ Project URL และ anon/public (publishable) key ใส่ config.js
   ห้ามใช้ service_role หรือ secret key ในไฟล์ HTML/GitHub
6. อัปโหลดไฟล์ HTML/CSS/JS ทั้งหมดขึ้น GitHub Pages
7. เปิด https://username.github.io/repository/owner.html แล้วล็อกอินจริง
8. เปิดหน้า QR ประจำโต๊ะเพื่อพิมพ์ QR ของแต่ละโต๊ะ

ข้อจำกัดที่ต้องทราบก่อนเปิดร้านจริง:
- QR โต๊ะที่สแกนแล้วเข้าหน้าเมนู สามารถถูกแชร์ลิงก์ได้ ใครมีลิงก์ก็อาจสั่งได้:
  เพิ่ม rate limit/CAPTCHA/การยืนยันโต๊ะ และมาตรการกันออเดอร์ปลอมก่อนเปิดจริง
- การล็อกอินและการป้องกันข้อมูลพนักงานต้องใช้ Supabase Auth + RLS:
  การซ่อนเมนูด้วย HTML อย่างเดียวไม่ใช่ระบบความปลอดภัย
- สำหรับโหมด Cloud ลูกค้าเข้าถึงได้เฉพาะรายการเมนูที่เปิดขายและสถานะบิลที่มี track_token;
  ไม่สามารถดึงรายการออเดอร์ทั้งหมดหรือจัดการเมนูผ่าน anon key
- ชำระเงินยังเป็นแบบพนักงานกดยืนยันเอง ไม่ได้ตรวจยอดธนาคารหรือรับเงินจริงอัตโนมัติ
- การกดลบออเดอร์เป็นการเปลี่ยนสถานะเป็น ยกเลิก เพื่อเก็บประวัติ
- การแก้ไขออเดอร์ที่ชำระเงินแล้วต้องมีขั้นตอนปรับยอด/คืนเงินก่อนเปิดใช้จริง
- เพิ่มส่วนกำหนดสิทธิ์พนักงานแยกบทบาท + audit log + สำรองข้อมูลก่อนใช้งานเต็มรูปแบบ
- ผู้ใช้ QR สแกนข้ามเครื่องจำเป็นต้องตั้งค่า Supabase ก่อน
